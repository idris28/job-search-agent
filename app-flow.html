Job Search Agent: Application Flow

From the jsa command you type, through each step of the logic, to the responses from the AI model, the browser, Gmail and the PostgreSQL database. Read it top to bottom.

    %% ---------- jsa run ----------

    R1 --> R2["run_agent()
pipeline.py"]
    R2 --> DB1[("PostgreSQL
active_profile, start_run")]
    DB1 --> R3["For each job board:
build_source().fetch()"]
    R3 --> W1[["Browserbase browser
fetch search page"]]
    W1 --> A1[["AI model
extract_listings: jobs, links, posted age"]]
    A1 --> R4["Drop links not on the page
sort newest first"]
    R4 --> W2[["Browserbase browser
fetch up to 15 job pages"]]
    W2 --> DB2[("PostgreSQL
upsert_job, stored once by fingerprint")]
    DB2 --> F{"reject_reason()
location, title, bank, older than 7 days?"}
    F -->|"rejected"| X1(["Dropped, no AI cost"])
    F -->|"kept"| H{"Already scored
with the same text?"}
    H -->|"yes"| X2(["Skipped"])
    H -->|"no"| A2[["AI model
score_job: 0 to 100, skills, gaps"]]
    A2 --> DB3[("PostgreSQL
save_match")]
    DB3 --> S{"Score 75 or more?"}
    S -->|"yes"| DB4[("PostgreSQL
shortlist_many")]
    S -->|"no"| DB5[("PostgreSQL
finish_run")]
    DB4 --> DB5
    DB5 --> O1(["Top new matches printed, newest first"])

    %% ---------- jsa add ----------

    D1 --> A3[["AI model

    A3 --> DB6[("PostgreSQL
upsert_job")]
    DB6 --> A4[["AI model
score_job"]]
    A4 --> DB7[("PostgreSQL
save_match, shortlist")]
    DB7 --> O2(["Job number and score printed"])

    %% ---------- jsa email ----------
    P -->|"jsa email"| E1["cmd_email()

    E1 --> DB8[("PostgreSQL

    W3 --> A5[["AI model

save_outreach")]
