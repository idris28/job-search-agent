Job Search Agent: Application Flow

From the jsa command you type, through each step of the logic, to the responses from the AI model, the browser, Gmail and the PostgreSQL database. Read it top to bottom.

flowchart TD
    U(["You type a jsa command
or launchd starts jsa daily"]) --> M["main()
cli.py"]
    M --> ENV["load_dotenv()
Settings.from_env()
read keys from .env"]
    ENV --> MIG{"Database up to date?
pending_migrations()"}
    MIG -->|"no"| X0(["Stops: Run jsa migrate"])
    MIG -->|"yes"| P{"build_parser()
which command?"}

    %% ---------- jsa run ----------
    P -->|"jsa run"| R1["cmd_run()
load config.yaml, create AI and browser"]
    R1 --> R2["run_agent()
pipeline.py"]
    R2 --> DB1[("PostgreSQL
active_profile, start_run")]
    DB1 --> B1{"For each source:
spending limit reached?"}
    B1 -->|"yes"| X3(["Source skipped, run marked partial"])
    B1 -->|"no"| K1{"Job board or
company feed?"}
    K1 -->|"job board"| W1[["Browser: Browserbase or local
fetch search page"]]
    W1 --> A1[["AI model
extract_listings: jobs, links, posted age
(the cheaper page model when one is set)"]]
    A1 --> W2[["Browser
open job pages not read yet, newest first,
up to max_detail_pages, each page once"]]
    K1 -->|"company feed"| FD[["Greenhouse, Lever, Ashby,
Amazon, Microsoft, Workday
HTTP feed, no browser"]]
    W2 --> DB2[("PostgreSQL
upsert_job: once per job,
also across boards")]
    FD --> DB2
    DB2 --> F{"reject_reason()
location, title, bank, too old?"}
    F -->|"rejected"| X1(["Dropped, no AI cost"])
    F -->|"kept"| RD{"Job-board job whose
own page was not read?"}
    RD -->|"yes"| X5(["Stored, scored after a later run reads its page"])
    RD -->|"no"| H{"Already scored, or a second
listing of a scored job?"}
    H -->|"yes"| X2(["Skipped"])
    H -->|"no"| B2{"Token limit reached?"}
    B2 -->|"yes"| X4(["Left for the next run"])
    B2 -->|"no"| A2[["AI model
score_job: 0 to 100, skills, gaps
profile sent as cached prefix
(a cheaper model may rule out clear misses first)"]]
    A2 --> DB3[("PostgreSQL
save_match")]
    DB3 --> S{"Score 75 or more?"}
    S -->|"yes"| DB4[("PostgreSQL
shortlist_many")]
    S -->|"no"| DB5[("PostgreSQL
finish_run: counts, and
the reason if partial")]
    DB4 --> DB5
    DB5 --> O1(["Top new matches printed, newest first"])

    %% ---------- jsa add ----------
    P -->|"jsa add"| D1["cmd_add()
read pasted post"]
    D1 --> A3[["AI model
read_pasted_job: role, company, email"]]
    A3 --> DB6[("PostgreSQL
upsert_job")]
    DB6 --> A4[["AI model
score_job"]]
    A4 --> DB7[("PostgreSQL
save_match, shortlist")]
    DB7 --> O2(["Job number and score printed"])

    %% ---------- jsa email ----------
    P -->|"jsa email"| E1["cmd_email()
load config and email_template.txt"]
    E1 --> DB8[("PostgreSQL
shortlisted_job_ids, get_job")]
    DB8 --> W3[["Browser
fetch live posting: still open?"]]
    W3 --> A5[["AI model
recruiter_email: fill the template"]]
    A5 --> E2["unfilled_placeholders()
flag any blank left"]
    E2 --> DB9[("PostgreSQL
save_outreach")]
    DB9 --> E3["emails_html()
write preview to digests/"]
    E3 --> G{"--gmail-drafts or --send?"}
    G -->|"neither"| O3(["Preview only, nothing sent"])
    G -->|"yes"| E4{"Ready?
address, open, no blank, not applied"}
    E4 -->|"no"| O4(["Listed with its apply link"])
    E4 -->|"yes"| E5["resume_for(): pick the CV
build_message(): attach it"]
    E5 --> K{"Which flag?"}
    K -->|"--gmail-drafts"| GM1[["Gmail
save_drafts"]]
    K -->|"--send"| CAP{"Under the daily cap?
sends_today()"}
    CAP -->|"no"| O10(["Not sent today, listed"])
    CAP -->|"yes"| GM2[["Gmail
send_messages, pause between emails"]]
    GM1 --> O5(["Drafts in Gmail for you to send"])
    GM2 --> DB10[("PostgreSQL
status = applied,
mark_outreach_sent")]
    DB10 --> O6(["Email sent to the recruiter"])

    %% ---------- jsa followups ----------
    P -->|"jsa followups"| FU1["cmd_followups()"]
    FU1 --> DB13[("PostgreSQL
followups_due: sent follow_up_days ago,
no follow-up yet")]
    DB13 --> FU2{"--send?"}
    FU2 -->|"no"| O11(["Follow-ups due listed"])
    FU2 -->|"yes"| GM3[["Gmail
send the stored follow-up
within the daily cap"]]
    GM3 --> DB14[("PostgreSQL
mark_follow_up_sent")]
    DB14 --> O12(["Follow-up sent once"])

    %% ---------- jsa apply ----------
    P -->|"jsa apply"| L1["cmd_apply()"]
    L1 --> DB11[("PostgreSQL
shortlisted_job_ids")]
    DB11 --> L2["Open the posting
in your own browser"]
    L2 --> L3{"Applied?
y / n / s / q"}
    L3 -->|"y or s"| DB12[("PostgreSQL
status = applied or skipped")]
    L3 -->|"n or q"| O7(["Left as shortlisted"])
    DB12 --> O8(["Status recorded"])

    %% ---------- jsa daily ----------
    P -->|"jsa daily"| DY1["cmd_daily()
run_agent(): the jsa run branch"]
    DY1 --> DB15[("PostgreSQL
top_matches of this run,
followups_due")]
    DB15 --> DY2["digest_markdown()
write digests/date.md"]
    DY2 --> GM4[["Gmail
one summary to your own address"]]
    GM4 --> O13(["Summary email and digest file"])

    %% ---------- jsa web ----------
    P -->|"jsa web"| WB1["web.serve()
page on 127.0.0.1:8765"]
    WB1 --> WB2["static/app.html
asks the JSON API for its data"]
    WB2 --> WB3{"What did you click?"}
    WB3 -->|"a quick change: status,
note, draft, send one email"| DB16[("PostgreSQL
changed in the request")]
    DB16 --> WB2
    WB3 -->|"a slow action: search,
draft emails, send all"| WB4["TaskRunner
runs the same jsa command
as a child process, one at a time"]
    WB4 --> O14(["Progress strip on the page, with Stop"])

    %% ---------- read-only commands ----------
    P -->|"jobs, show, applications,
digest, runs"| Q1[("PostgreSQL
read only")]
    Q1 --> O9(["Table or summary printed"])

Step in the agent's code Decision PostgreSQL database Outside service: AI model, browser, company feeds, Gmail Start or result
BranchEntry functionWhat comes back
jsa runcmd_run() then run_agent() in pipeline.pyJobs and scores stored, strong matches shortlisted, a summary printed
jsa addcmd_add()One pasted post stored, scored and shortlisted
jsa emailcmd_email() then _deliver()A draft per job, an HTML preview, and optionally Gmail drafts or sent emails
jsa applycmd_apply()Each posting opened in your browser, your answer recorded
jsa followupscmd_followups()Follow-ups due listed, or sent once each with --send
jsa dailycmd_daily(), started by jsa schedule installA run, a digest file and one summary email to you
jsa webcmd_web() then web.serve()A local page where every command is a button; slow ones run as one background task at a time
Read-only commandscmd_jobs(), cmd_show() and othersTables read straight from the database
